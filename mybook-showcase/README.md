# MyBook — sito vetrina

Sito statico responsive per MyBook. Le schermate autentiche del manuale sono incluse nella cartella `assets/` e presentate in un carosello orizzontale con controlli di navigazione, scorrimento touch e tastiera. Clicca su una schermata per aprirla ingrandita; puoi chiuderla con il pulsante, cliccando sullo sfondo o premendo Esc.

## Anteprima

Apri `index.html` in un browser.

## Pubblicazione

Carica l'intera cartella mantenendo `index.html` e `assets/` nella stessa directory. Il sito non richiede build né dipendenze. Il logo e i font esterni richiedono una connessione internet.
